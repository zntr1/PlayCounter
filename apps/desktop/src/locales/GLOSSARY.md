# PlayCounter glossary

Every translation uses these words for PlayCounter's own terms, in every
area file. English is the source (`src/locales/en`). Brand and product names
stay as they are: PlayCounter, Steam, Xbox, Battle.net, Epic Games, IGDB,
Discord, Windows, Dolphin, DOSBox, PCSX2, mGBA.

## Deutsch (de) — approved 2026-10-10

**Style**

- Address the player with **du**, lowercase (du, dein, dir). Friendly and
  short, like the English.
- Page names and button labels inside a sentence in „…“: „Entdeckt“ öffnen,
  klick auf „Filter speichern“.
- German quotes „…“, ellipsis …, no space before ! or ?.
- Playtime durations stay as in English: 12h 3m, 3d 4h, <1m, vor 5m. Words
  in sentences are German (ab 10 Minuten, 2 Sek. halten).
- Dates and numbers come from the app (Intl), never written by hand.
- A text that gets a name inserted where German needs a case: write the
  stand-in in that case ("this game" = „diesem Spiel“ in „gehört nicht zu
  {{game}}“) or reword so the name stands alone.

## Português (Brasil), Español, 中文（简体） — translation drafts

These languages use the same English source and area files as German.
Navigation labels and the terms below have been reviewed for consistency;
the complete translations still need native-speaker review.

**Style**

- Brazilian Portuguese (`pt-BR`): address the player as **você**. Use Brazilian
  spellings such as arquivo, salvar, tela, and usuário. Use **launcher** for a
  game launcher, as Brazilian players commonly do.
- Spanish (`es`): address the player as **tú**, with concise, broadly understood
  Spanish. Use archivo, guardar, pantalla, and usuario.
- Simplified Chinese (`zh-CN`): address the player as **你**, using Simplified
  characters. A match means a file-to-game association, never a competition.
  A session means a recorded period of play, never a meeting.
- Page names inside instructions match the navigation labels below. Brand
  names, filenames, keyboard shortcuts, placeholders, and markup stay intact.
- Portuguese and Spanish keep compact duration units (12h 3m). Chinese uses
  localized units (12小时 3分钟). Dates and numbers are formatted by Intl.
- Portuguese and Spanish have `one`, `many`, and `other` plural forms;
  `many` uses the same wording as `other`. Chinese has only `other`.
- Button and setting names inside instructions are quoted exactly as the
  control shows them: “…”, with ‘…’ for a name inside a quoted name.
  Spanish and Portuguese leave page names unquoted; Chinese quotes them too.
- Spanish says **el PC** (este PC, otro PC) and **añadir**, not agregar.
- Portuguese says **app** (not aplicativo) and **o Steam** (no Steam, do Steam).
- Sample game names in guides stay in English (World of Warcraft, Zelda),
  because the sample cards and the sample search use the English names.

## Русский, Polski, Français — translation drafts

Same English source and area files. Written 2026-10-14; they still need
native-speaker review (Weblate).

**Style**

- Russian (`ru`): address the player as **вы**, lowercase. Guillemets «…» for
  page and button names. Durations use Russian units: 12 ч 3 мин, 3 д 4 ч.
- Polish (`pl`): address the player as **ty**, lowercase. Never use gendered
  past-tense forms for the player (zrobiłeś/zrobiłaś): rephrase with present
  tense, an impersonal form or a noun. Quotes „…” for button and setting names;
  page names stay unquoted, like in Spanish. Durations: 12 h 3 min, 3 d 4 h.
- French (`fr`): address the player as **vous**. Avoid past participles that
  agree with the player (prêt, connecté, arrêté): rephrase. Guillemets « … »,
  with a no-break space before : ; ! ? and inside « ».
  Durations: 12 h 3 min, 3 j 4 h.
- Plurals: Russian and Polish need `one`, `few`, `many` and `other`; `other`
  covers fractions and uses the `few` (ru) or `many` (pl) wording. French has
  `one`, `many` and `other`; `many` uses the same wording as `other`.
- A count without plural keys becomes a label: "Найдено новых приложений: 3",
  "Znalezione nowe aplikacje: 3".
- A stand-in that fills a {{placeholder}} is written in the case its sentences
  need: ru "this game" = этой игре (dative/prepositional), pl = tej gry
  (genitive), fr = ce jeu.
- Sample names stay as in English (World of Warcraft, Zelda, Speedrun); the
  sample note uses the official place names (ru Западный Край, Штормград;
  fr Marche de l'Ouest, Hurlevent; pl stays English, like Polish WoW).
- Tauri has no Polish installer texts, so `src-tauri/nsis/Polish.nsh` holds
  them (`customLanguageFiles` in tauri.conf.json).
