# Tour artwork

These images ship with the desktop app so sample games have artwork without
downloading images during a tour.
The banner uses the same backdrop and title bar rendering as a running game.

World of Warcraft and Diablo IV artwork belongs to Blizzard Entertainment,
Grand Theft Auto V artwork to Rockstar Games, and The Legend of Zelda artwork
to Nintendo. These third-party images are not covered by PlayCounter's MIT license.

- `world-of-warcraft-banner.jpg` (2400 x 1350): official artwork from
  [World of Warcraft Classic Is Now Live!](https://worldofwarcraft.blizzard.com/en-us/news/23099309/world-of-warcraft-classic-is-now-live),
  downloaded unchanged from
  [Blizzard's CDN](https://bnetcmsus-a.akamaihd.net/cms/blog_header/8g/8G9PJA14T3FN1566592377439.jpg).
- `world-of-warcraft-cover.webp`: the existing demo cover, downloaded at twice
  the original resolution from
  [IGDB](https://images.igdb.com/igdb/image/upload/t_cover_big_2x/co2l7z.webp).
- `gta-v-cover.webp`: [IGDB cover](https://images.igdb.com/igdb/image/upload/t_cover_big/co2lbd.webp).
- `zelda-wind-waker-cover.webp`: [IGDB cover](https://images.igdb.com/igdb/image/upload/t_cover_big/co3ohz.webp).
- `diablo-iv-cover.webp`: [IGDB cover](https://images.igdb.com/igdb/image/upload/t_cover_big/co69sm.webp).
