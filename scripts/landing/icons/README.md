# Game glyphs for the homepage

Inlined by `build.mjs` into the "Popular games" tiles, colored by CSS.

- `roblox.svg`, `fortnite.svg`, `leagueoflegends.svg`, `valorant.svg`,
  `rockstargames.svg`: [Simple Icons](https://simpleicons.org) 16.32.0, CC0-1.0.
- `pickaxe.svg`, `swords.svg`: [Lucide](https://lucide.dev) 0.544.0, ISC.
  Generic stand-ins for Minecraft and World of Warcraft: Simple Icons removed
  its Minecraft logo in v13 and has no World of Warcraft logo.
- `infinity.svg`: [Lucide](https://lucide.dev) 0.511.0, ISC. Generic stand-in
  for World of Warcraft: Forever.

The game names and logos are trademarks of their owners; the tiles only link
to PlayCounter's guides for those games.
