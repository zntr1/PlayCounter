# PlayCounter v1.3.1

Correct digital signatures for the PlayCounter app and its uninstaller.

### Fixes

- **The PlayCounter app is now correctly signed** by itvis UG, so Windows and virus scanners can check that it is genuine. Before, only the installer's signature was valid: a mistake in our build broke the signature of the app inside it (all versions up to 1.3.0).
- **The uninstaller is signed too.**

Nothing else changed: same features as 1.3.0.

This is a pre-release, so PlayCounter will not offer it as an update. Your app is fine as it is. The next regular update will include this fix. To install it now, use the Windows installer attached to this release.
