# PlayCounter v1.6.0

Bring in your PlayStation games, see how long a game takes and look back at any dates in My History.

### Your PlayStation games, too

Import your **PS5 and PS4** games with the playtime Sony recorded. While you play on the console, PlayCounter counts the session live, and the **Achievements** tab shows your trophies.

Right-click **My Games** in the sidebar → **Import from PlayStation**. Live sessions can be switched off under **Launcher accounts → Live from PlayStation**.

### How long to beat

Game details get a **How long to beat** tab: how long a game takes (Main story, Main + extras, Completionist), how far you are and how much is left. **Mark finished** right there, and **Add my time on HowLongToBeat** opens HowLongToBeat's form, with your values ready to copy.

### My History for any dates

Step through months, weeks or days with the arrows on the range, or use **Pick dates**. See which games you played when, how it compares with the time before, your game seasons and a calendar of covers. My History now opens on **Insights**.

### New games up front

Games you added in the last 7 days and haven't played yet wait in a row above My Games. A big import shows as one card. Games leave the row once you play them, or all at once with **Mark all as seen**.

### More

- **Several accounts per launcher:** each account keeps its own hours of a game, and PlayCounter adds them up. Game details show each account's hours under **Files → Where it came from**.
- **New playtime first:** when you import again, **Already in My Games** starts with the games that have new playtime, ready to update. Import stays in one spot, and each tab imports only its own games.
- **Status and shelves from the menu:** right-click a game to set its status or put it on a shelf. Each status has its own icon and color on the cover.
- **Sort achievements** by unlock date, rarity or name.
- **Less memory while you play:** the timer on your game no longer uses more and more memory during long sessions.

### Fixes

- Banner art stays sharp after it fades in.
- Game details show Yes, No and similar values in your language.
- Xbox achievements you haven't started no longer show an empty progress bar.
- Steam games found through a shared file name like Game.exe are no longer sent for community review.

Update from **Settings → Updates** in PlayCounter, or use the Windows installer attached to this release.
