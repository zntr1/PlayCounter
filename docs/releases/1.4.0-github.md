# PlayCounter v1.4.0

PlayCounter now speaks German, Portuguese (Brazil), Spanish and Chinese.

### Languages

- PlayCounter starts in your computer's language. Change it any time in **Settings → General → Language**. **System** follows your computer and falls back to English.
- Prefer English? On the first start after the update, one click on **Switch to English** takes you back.
- The installer, the startup screen and **What's new** are translated too.
- Dates and numbers follow your language.

### Improvements

- **My History → All time:** the total at the top now matches **My Games**, launcher playtime and your own edits included.
- PlayCounter games without a file now get help finding one:
  - **Move to PlayCounter** keeps the files PlayCounter knows for the game.
  - A file found at startup shows as **Match found** and in **Level up all**.
  - **Check for matches** works for them too.

### Fixes

- Ignoring an app no longer sends it to the community as a software suggestion.
- More Windows tools and helper programs (like Defrag or the on-screen keyboard) are ignored automatically.

Update from **Settings → Updates** in PlayCounter, or use the Windows installer attached to this release.
