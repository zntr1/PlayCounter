# PlayCounter v1.1.18

Drag games onto shelves together, import games with fewer clicks, and choose whether playthrough names appear in your popups.

- **Add several games to a shelf at once.** Use Select in My Games, then drag any selected game to add the whole group to Favorites or a shelf. The drag preview shows how many games you are carrying. Games already on the destination shelf are skipped.
- **Easier Steam and Xbox imports.** When only one suitable game file is found, it is preselected for your review. You still confirm before adding the game. If several files need a choice, you can pick the right one yourself.
- **Accurate import confirmations.** Messages now distinguish an existing game-file match from a new community submission. Linking a known match no longer claims the file was sent for review, and failed verification clearly asks you to try again.
- **Optional playthrough names in popups.** Names are now off by default in game-start and saved-session popups. Enable **Playthrough names in popups** under **Settings → Desktop popups** to show them. **Notes in game-start popups** remains a separate option, also off by default.
- **Better recovery from temporary server limits.** A countdown shows when online requests can resume. Background game lookups retry automatically, while Steam and Xbox imports can wait and continue after a pause. Cancel remains available while waiting. These pauses no longer make PlayCounter report a lost connection or treat an unchecked game as an unknown match.
- **Consistent emulator match badges.** Community, Custom, and IGDB badges now reflect how the emulator game was matched across My Games, active sessions, history, emulator pages, and game details. Pending community reviews are shown correctly, and older sessions do not inherit badges from a replacement game match.
- **A clearer empty library.** My Games explains how automatic detection works when you have no games yet. Steam and Xbox imports are offered as optional ways to bring in games and past playtime.
- **Detection fix.** Games using `defrag.exe` can now be checked for a match.

Update from **Settings → Updates** in PlayCounter, or use the Windows installer attached to this release.
