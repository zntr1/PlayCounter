# PlayCounter v1.4.1

Six new emulators, three new languages and a note for every session.

### Emulators

PlayCounter now tracks games in six more emulators. Each game counts on its own, like with Dolphin or PCSX2:

- **Cemu** (Wii U)
- **RPCS3** (PlayStation 3)
- **PPSSPP** (PSP)
- **DuckStation** (PlayStation)
- **Ryujinx** and **Eden** (Nintendo Switch)

### Languages

- PlayCounter now also speaks **French, Polish and Russian**. Change it any time in **Settings → General → Language**.
- The installer and **What's new** are translated too.

### Session notes

- Write a note for each session, in **My History** or in the game's **Journal**.
- Set a **Quick session note** shortcut in **Settings → Keyboard shortcuts**. It opens a small note box over your game; **Enter** saves and takes you back to the game.
- Turn on **Session notes in popups** in **Settings → Desktop popups** to get an **Add session note** button when a session is saved.

### Improvements

- Point at a game card for **Journal** and **More**.
- Notes, playthroughs and shelves now share one **Journal** item in the card menu. Cover and banner sit under **Appearance**.
- **Check for matches**: when the only match is the one you already have, **Keep current match** is the main button.
- **Ignore** and **Remove** dialogs: the buttons are stacked, and the delete button says how many sessions it deletes.

### Fixes

- Emulator programs no longer show up in **Discovered**.
- A game file you pick with **Start game** on an emulator page is remembered.
- A broken entry in Steam's files no longer stops the Steam lookup.
- Keyboard shortcuts can be recorded in every language.

Update from **Settings → Updates** in PlayCounter, or use the Windows installer attached to this release.
