# PlayCounter v1.3.2

Level up all your games at once, pick a cover for any game, and clearer ways to report a wrong match.

### Level up all

- **Level up all** in My Games lists every game that can be improved: suggestions the community approved, matches found for your own games, and launcher games PlayCounter can now track.
- Everything starts ticked. Untick what looks wrong and apply the rest.

### Covers for any game

- **Choose cover…** picks a SteamGridDB cover for any game, not only your own. It shows everywhere the game appears.
- **Upload cover** and **Paste Cover** use your own image. **Restore Cover** brings back the original.
- A cover that can't load (for example after restoring a backup on another PC) falls back to the game's original cover.

### Clearer reports

- **Report wrong match** asks what the file really is: a different game, an app to track, an app to ignore, part of the game, or not sure.
- New: **It doesn't belong to &lt;game&gt;** takes one file off a game on your PC and reports it. Its sessions stay in My History.
- Games with several .exes ask **Which file?**, so reports, match checks and **Convert to custom game** act on the right one.
- **Details → Files** has a **Report** button for every file, even files that never ran.
- Now Playing: an unknown program gets one **Not a game…** button with the same choices.

### More new stuff

- **Hide to tray when a game starts:** after you press Play in PlayCounter, it moves to the tray once the game runs. On by default in **Settings → Game launching**.
- **Start page:** open on Now Playing or My Games (**Settings → General**).
- **Clock in the session popup:** optional time of day, handy in fullscreen games (**Settings → Keyboard shortcuts**).
- **Sidebar:** emulators moved to **Library**, Software to **Discover**.
- **My History:** a **Back to top** button, and the All time games list now matches your My Games totals, launcher playtime included.
- **Escape** clears the search or the My History filter from any page. On Discovered, **Ctrl+F** jumps to its own search.

### Fixes

- A game's .exe no longer shows twice when only upper and lower case differ (cs2.exe and CS2.exe).
- Picking a different game for a file no longer keeps the old game's details and art.
- **It's a different game** and **Suggest to Community** on a game with two files now save to the right file.
- The app and its uninstaller are correctly signed. This fix was first in the 1.3.1 pre-release.

Update from **Settings → Updates** in PlayCounter, or use the Windows installer attached to this release.
