# PlayCounter v1.3.0

Add any game yourself, track your apps as software, PlayStation controllers and mGBA.

### Add games yourself

- **Add game** in My Games: by title or IGDB ID, with or without its .exe.
- **Set launch file** replaces "Not launchable". Xbox games get **Open in Xbox**.
- **Change Game** fixes a wrong link on your PC.
- **Suggest to Community** shares your own game in one click.
- **Files** tab: see who matched each .exe and remove your own.

### Software tracking

- **Track software** counts Discord, Spotify, launchers and more on their own **Software** page.
- Stats per app, your own art, never mixed with game time.
- Apps and games on the same .exe are told apart.

### More new stuff

- **PlayStation controllers:** DualSense and DualShock 4, with PlayStation button hints.
- **mGBA:** Game Boy, Game Boy Color and Game Boy Advance games.
- **RPG Maker & Game.exe games:** one card per game folder.
- **Discovered:** clearer review with product name, publisher, folder and a "Probably a game" hint.
- **My Games:** **Recently added** sort, **New** badge, better **Launchable** filters, IGDB ID search, optional **18+ art**.
- **About 40% less memory** in the tray.

### Fixes

- Unreadable saved data is never saved over.
- A broken page no longer blanks the window.
- Fixes for the tray banner, sorting in Last played and the Ignore/Remove dialogs.

Update from **Settings → Updates** in PlayCounter, or use the Windows installer attached to this release.
