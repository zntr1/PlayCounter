**PlayCounter 1.4.1 is out** 🎮

🕹️ **Six new emulators:** Cemu (Wii U) · RPCS3 (PS3) · PPSSPP (PSP) · DuckStation (PS1) · Ryujinx and Eden (Switch), each game counted on its own
🌍 **Three new languages:** Français · Polski · Русский, installer included
📝 **Session notes:** write down what happened in a session, in My History or the game's Journal
⌨️ **Quick session note:** set a shortcut in Settings → Keyboard shortcuts and write a note over your game without leaving it
🃏 **Slimmer card menu:** point at a card for Journal and More; notes, playthroughs and shelves now share one Journal item
🧹 **Emulator programs** no longer show up in Discovered
💾 **Start game** remembers the game file you picked
🔧 **Steam lookup** no longer stops on a broken entry in Steam's files

Update from **Settings → Updates**, or [download PlayCounter 1.4.1 for Windows](https://github.com/zntr1/PlayCounter/releases/tag/v1.4.1).
